# Realty 2.2.0

A freehold no longer accepts offers until its titleholder turns them on. This release changes the database, so the plugin and `realty-rest` must be upgraded together.

## Upgrade

`realty-rest` 2.2.0 refuses to start against a database schema other than version 20. The plugin moves the database to version 20 the first time it starts.

1. Stop `realty-rest`.
2. Replace the Realty plugin jar with its 2.2.0 version and restart the game server. When the migration has finished, the log shows `Applied migration V20: offers off by default`.
3. Replace `realty-rest` with its 2.2.0 version and start it. Do this only after step 2: `realty-rest` 2.2.0 refuses to start until the migration has run.

The modules can stay on 2.0.

## Changes in behaviour

- **Offers are off until the titleholder turns them on.** A new freehold refuses offers. Its titleholder, or a sanctioned auctioneer, turns them on with `/realty offer toggle true`. A player who tries to make an offer on a freehold that refuses them is told so.
- **Existing freeholds turn off too.** The migration turns offers off on every freehold, except one with an offer on it. That offer may still be open, or accepted and being paid for. Those freeholds keep accepting offers, so no buyer is stranded.
- **Every player can use `/realty offer toggle`.** The permission `realty.command.offer.toggle` now defaults to `true`, because a titleholder needs it to turn offers on. Realty still checks that the player holds the title or is a sanctioned auctioneer. `realty.command.offer.toggle.bypass`, which skips that check, stays op-only. A server that set `realty.command.offer.toggle` in its permissions plugin keeps its own setting.

## For plugin developers

- **A new freehold refuses offers.** `placeOffer` on a freehold that has not had offers turned on returns `OfferResult.NotAcceptingOffers`. Turn them on with `toggleOffers`.
- **`listOfferListings()` lists fewer freeholds after the upgrade.** It lists only freeholds that accept offers, or are still being paid for through one.
